Contact & Technical Support

We welcome questions, issue reports, integration feedback, and feature proposals for Twitter CLI. Below are the official contact and support channels available to users, developers, and autonomous agent integrators.

Primary Support Channels

  • GitHub Issues: For bug reports, unexpected behavior, and enhancement proposals, visit our tracker at github.com/SpaceCorps/Twitter-Cli/issues.
  • GitHub Discussions: For questions, agent integration patterns, and community discussion, visit github.com/SpaceCorps/Twitter-Cli/discussions.
  • SpaceCorps Organization: To explore our open-source tools and CLI ports, visit github.com/SpaceCorps.

Security Inquiries

If you discover a security vulnerability involving credential storage or process isolation, please report it privately via GitHub Vulnerability Reporting on the repository page.

Apify Platform Inquiries

For questions related to Apify actor pricing, compute credits, or account limits for the apidojo/tweet-scraper actor, consult apify.com or the Apify Console.
